## MSIM Course Hub — Vite + React app

This project implements the Figma landing page design (node `1:12`) as a Vite + React application.

### Getting started

From the project root:

```bash
npm install
npm run dev
```

Then open the printed local URL (by default `http://localhost:5173`).

### Design tokens

Key colors:

- **Background**: `#FCF7F3`
- **Gold label**: `#DCA624`
- **Heading**: `#2D1F2A`
- **Subtitle**: `#8E7998`
- **Ink tertiary (border)**: `#9C8F80`
- **Ink ghost (divider)**: `#C4B8AA`

Fonts: **Instrument Serif** (headings, nav), **Inter** (labels, search).
